# VOTE — LINE Mini App

ระบบโหวตบน LINE Mini App โดยอ้างอิงผู้ใช้และกลุ่มจาก LINE

## โครงสร้าง
- `design/` — งานออกแบบต้นแบบจาก Figma Make (`design/public/vote.html`, `design/public/vote-app.html`) ใช้เป็นแบบอ้างอิงหน้าตา

## ดูงานออกแบบ
```bash
npx http-server design/public -p 5180
# เปิด http://localhost:5180/vote.html
```
